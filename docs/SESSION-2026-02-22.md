## Accomplishments

### 1. Diagnosis of Experiment 1 Failure (Vocabulary Extension)

**Problem:** After fine-tuning with an extended vocabulary (2454 → 2459 tokens), the model produced unintelligible speech. Audio quality degraded severely — the model appeared to ignore text and reconstruct reference audio instead.

**Root Cause Investigation:**
- Researched all relevant issues on `gokhaneraslan/chatterbox-finetuning`: #3, #5, #6, #7, #8, #12, #14
- Found that the upstream maintainer confirmed (Feb 20, 2026) the exact same problem: new token embeddings initialized with the mean of existing embeddings produce a "weak/blurry" signal
- The strong audio encoder dominates, and the model collapses into an autoencoder (posterior collapse)
- Multiple users reported identical symptoms: Turkish (#6), Norwegian/German (#12), Arabic (#14)
- Also examined `stlohrey/chatterbox-finetuning` (alternative repo) for cross-reference

**Conclusion:** Vocabulary extension is fundamentally incompatible with the current Chatterbox fine-tuning approach for new languages. The signal imbalance between weak new embeddings and the strong audio encoder causes structural failure.

### 2. Full Tokenizer Vocabulary Analysis

Fetched and analyzed the complete `grapheme_mtl_merged_expanded_v1.json` tokenizer (2,454 tokens) from HuggingFace to determine which Romanian characters were already present.

**Key Findings:**

| Character | In Vocab? | Token ID | Approach |
|-----------|-----------|----------|----------|
| ă (a-breve) | ✅ Yes | 2413 | Keep as-is |
| â (a-circumflex) | ✅ Yes | 395 | Keep as-is |
| î (i-circumflex) | ✅ Yes | 407 | Keep as-is |
| ș (s-comma) | ❌ No | — | Map to `sh` (ID 120) |
| ț (t-comma) | ❌ No | — | Map to `ts` (ID 192) |

**Critical Insight:** Only 2 of 5 "missing" characters truly need mapping. The vowels ă, â, î already have well-trained embeddings. The consonants ș and ț have phonetically exact English equivalents (`sh` = /ʃ/, `ts` = /ts/) already present as BPE tokens.

## Bug Fixes

### 1. Inference Callback `exaggeration` Tuple Bug
**File:** `src/inference_callback.py`, line 153
**Bug:** `params["exaggeration"] = 1.2,` — trailing comma creates tuple `(1.2,)` instead of float `1.2`
**Error:** `TypeError: only integer tensors of a single element can be converted to an index`
**Fix:** Removed trailing comma → `params["exaggeration"] = 1.2`

### 2. Timestamped Output Directory Prevents Resume
**File:** `src/config.py`
**Bug:** `output_dir = f"/data/output/chatterbox_output_{datetime.now()...}"` creates a new directory each run
**Impact:** `train.py`'s auto-resume never finds previous checkpoints
**Fix:** Changed to fixed path `"/data/output/chatterbox_output_ro_phoneme"`
